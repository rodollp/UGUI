# 덱빌딩 로그라이크 — 실행과 시스템

Unity **6000.6.7f1**에서 Assets/Scenes/CardGame.unity를 열고 재생한 뒤 START를 누른다.
분기 맵이 열리고, 밝은 노드를 클릭하면 전투 또는 사건에 들어간다.

## 주요 흐름

1. 새 회차: 체력·시작 덱·골드와 분기 맵을 생성한다.
2. 맵: 연결된 다음 층 중 하나를 클릭해 선택한다.
3. 전투: 플레이어 턴과 적 턴을 번갈아 진행한다.
4. 승리: 골드 1회 지급 → 카드 3장 중 1장 선택 → 맵 복귀.
5. 사건·휴식·보물: 선택에 따른 효과 적용 → 결과 확인 → 맵 복귀.
6. 마지막 보스를 처치하고 보상을 처리하면 탐험을 완료한다.

전투와 사건 사이에 체력·골드·회차 덱은 유지된다.
전투의 힘·민첩·방어도·디버프는 다음 전투 시작에 초기화된다.
패배하면 해당 노드는 완료되지 않으며 같은 회차를 계속 진행할 수 없다.
타이틀에서 새 회차를 시작할 수 있다.

## 구성 요소

| 구성 | 책임 |
| --- | --- |
| RunManager | 회차 체력·덱·골드와 맵 진행 |
| RunMapData / RunMap | 노드 종류·후보 설정, 분기 경로와 이동 가능 여부 |
| AdventureController | 맵 선택·전투 진입·사건 처리·맵 복귀 |
| RunMapUI / MapEventUI | 클릭 가능한 맵과 선택형 사건 화면 |
| EncounterData / EnemyData | 적 조합·배치와 적 행동 패턴 |
| BattleManager | 적 생성, 턴 진행, 승패와 승리 보상 |
| CardManager / BattleDeck | 카드 사용, 에너지 검증과 전투 카드 순환 |
| PlayerStatus / CreatureStatus | 체력·에너지·방어·힘·민첩·디버프 |
| BattleRewardUI | 카드 3장 중 1장 선택 |
| PlayHUD / UIScreenFlowController | 화면 전환과 전투 상태 표시 |

## 상세 문서

- AdventureMap.md: 맵·사건 데이터 설정과 전체 흐름 검증.
- VictoryRewards.md: 골드와 카드 보상.
- Debuffs.md: 취약·약화·손상과 지속시간.
- EnemyPatterns.md: 실제 적 데이터와 패턴 실행 확인.

RunManager의 Map Data가 없을 때만 기존 StageData 순차 진행을 호환 모드로 사용한다.
실제 씬은 맵 모드로 연결되어 있으며, 기존 전투 회귀 검증은 별도의 호환 모드 설정을 사용한다.

## 이후 확장

다중 상품 상점, 유물, 추가 상태이상, 카드 강화, 보존·소멸 키워드, 애니메이션,
여러 막의 연결과 진행 저장은 후속 확장 대상이다.
