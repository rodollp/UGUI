# 전투와 층 진행

## 실행

Unity **6000.6.7f1**에서 `Assets/Scenes/CardGame.unity`를 열고 재생한 뒤 START를 누른다.
씬과 샘플 데이터는 연결되어 있다. 별도 Inspector 설정 없이 3개 층을 시험할 수 있다.

1. 1층: 고블린 1마리
2. 2층: 고블린과 수호병 2마리
3. 3층: 우두머리

카드를 적에게 드래그하면 공격한다. 대상이 없는 카드는 화면 아래쪽의 사용 경계를 넘어 놓는다.
에너지가 부족하거나 대상이 잘못되면 카드를 소비하지 않는다.
턴 종료 버튼을 누르면 손패를 버리고 살아 있는 적들이 표시된 행동을 순서대로 실행한다.
승리 화면의 '다음 층' 버튼으로 이동하며, 마지막 층에서는 회차 클리어를 표시한다.
패배하면 다음 층으로 갈 수 없다. 타이틀에서 새 회차를 시작할 수 있다.

## 역할

| 구성 | 책임 |
| --- | --- |
| RunManager | 회차의 체력, 덱, 현재 층과 선택된 적 조합 유지 |
| StageData | 층의 이름·종류·등장 가능한 적 조합 |
| EncounterData | 한 전투의 적 프리팹·EnemyData·로컬 배치 좌표 |
| EnemyData | 이름·체력·일반/엘리트/보스 분류·반복 행동 패턴 |
| BattleManager | 적 생성·턴 상태·행동 순서·전투 종료·전투 정리 |
| CardManager | 손패·드로우·비용 및 대상 검증·카드 효과 실행 |
| PlayerStatus | 에너지 관리, CreatureStatus에서 체력·방어·힘·민첩 상속 |
| PlayHUD | 에너지·층·턴·적 행동 예고·결과·진행 버튼 표시 |

## 전투 규칙

- 플레이어 턴 시작: 방어도 초기화 → 최대 에너지 회복 → 5장 드로우.
- 카드 비용은 CardInstance.CurrentCost를 사용한다. 음수 비용은 지원하지 않는다.
- 카드 효과로 최대치를 넘는 에너지를 얻을 수 있고, 다음 턴에는 최대치로 재설정한다.
- 에너지 획득·회복 카드는 Create → Card Effects → Gain Energy / Heal로 효과 에셋을 만든다.
- 공격에는 힘, 방어 카드에는 민첩을 더한다.
- 손패 최대 10장. 드로우 더미가 비면 버린 더미를 섞는다.
- 파워 카드는 사용 후 해당 전투의 카드 순환에서 빠진다. 회차 덱에서는 제거하지 않는다.
- 적은 자신의 턴 시작 시 기존 방어도를 제거하고, 예고했던 행동을 실행한다.
- 행동은 공격(다중 타격 포함), 방어, 힘 증가를 지원하며 Actions 배열 순서대로 반복한다.
- 죽은 적은 행동·대상 지정에서 제외한다.
- 적 턴·일시정지·전투 종료 상태에서는 카드를 사용할 수 없다.
- 한 카드의 모든 효과가 처리된 뒤 적 전멸을 판정한다. 플레이어 사망은 즉시 패배 처리한다.
- 다음 전투에서는 동일한 플레이어 상태와 회차 덱을 유지한다. 체력을 자동 회복하지 않는다.
- 전투용 힘·민첩·방어도는 초기화하고, 카드 더미와 적 상태는 새로 만든다.
- 타이틀 복귀 시 적과 코루틴·이벤트 구독을 정리한다.

## 적과 층 추가

1. Create → Battle → Enemy: EnemyData를 만들고 체력과 행동 배열을 설정한다.
2. Create → Battle → Encounter: Enemies 배열에 프리팹·EnemyData·배치 좌표를 추가한다.
   현재 Normal 프리팹은 임시 공통 외형이다. 적마다 다른 프리팹을 연결할 수 있다.
3. Create → Battle → Stage: Encounters 배열에 등장 가능한 조합을 넣는다.
4. RunManager의 Stages 배열에 층 순서대로 등록한다.

해당 층에 들어갈 조합은 한 번 선택해 저장한다. 각 전투는 적을 새로 생성한다.
Stages가 비어 있으면 BattleManager의 Encounter를 단일 전투로 사용한다.
설정이 누락된 조합은 전투를 시작하지 않고 오류를 출력한다.

샘플을 다시 구성하려면 Tools → Battle → Configure Sample Battles를 실행한다.
이 명령은 CardGame 씬의 직접 배치된 적, 샘플 전투 에셋과 관련 UI 연결을 다시 설정한다.
사용자 지정 씬을 편집 중이라면 먼저 저장하고 실행한다.

## 검증

배치 모드에서 실제 씬을 재생하는 검증 진입점:

```text
Unity.exe -batchmode -nographics -projectPath "<GameUIUXLab 경로>" -executeMethod BattleValidation.Run -logFile "<로그 경로>"
```

`-quit`은 붙이지 않는다. 검증이 끝나면 성공은 종료 코드 0, 실패는 1로 종료한다.
에너지·회복·전투 초기화·카드 순환·적 행동 패턴과 실제 씬의 비용·턴·승패·층 이동을 검사한다.
그래픽 장치가 있는 실행에서는 프로젝트 폴더의 두 단계 위에 battle-preview.png도 저장한다.
이 검증은 연결된 샘플 씬과 3개 층 데이터를 기준으로 한다.

## 이후 확장

현재는 순차적인 3층 전투의 기반이다. 분기 지도, 노드 선택, 상점·휴식·이벤트,
전투 보상, 유물, 상태이상, 보존·소멸 키워드, 애니메이션은 후속 작업으로 분리한다.
StageType과 EnemyType의 Elite 값은 분류용이며 별도의 보상 규칙은 아직 없다.
