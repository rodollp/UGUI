# UI 변경 감지와 갱신

## 지도

- `RunMapUI`는 실제 `RunMap` 참조가 바뀔 때만 노드와 경로 오브젝트를 생성한다.
- 같은 맵으로 돌아오면 기존 버튼·아이콘·층수·점선 오브젝트를 재사용한다.
- 골드 변경은 `RefreshStatus()`만 호출한다. 체력·골드·덱 수가 이전 표시와 같으면 문자열을 만들지 않는다.
- 활성 노드·완료 노드·플레이어 생존 상태가 같으면 지도 상태 갱신도 생략한다.
- 노드의 선택 가능/완료 상태가 달라질 때만 아이콘 메시를 갱신한다.
- 완료 경로의 색만 변경하며 새로운 점선 오브젝트를 만들지 않는다.
- 같은 상태에서 Refresh를 호출해도 사용자가 이동한 스크롤 위치를 유지한다.

## HUD

- 전투·골드 변경 알림은 Dirty Flag를 설정한다.
- `LateUpdate()`에서 해당 프레임의 최종 상태를 한 번 읽는다.
- 골드·턴·에너지·층 이름은 마지막으로 표시한 값과 달라질 때만 문자열을 만든다.
- 적 상태와 행동 예고를 비교하고 변경이 있을 때만 예고 문구를 만든다. StringBuilder를 재사용한다.
- 시간은 표시할 초가 달라질 때만 갱신한다.
- 결과 및 다음 이동 버튼은 클릭 직후에도 올바르게 작동하도록 즉시 상태를 동기화하되, 같은 값은 다시 쓰지 않는다.
- OnEnable과 명시적 ResetHUD는 초기 화면을 즉시 갱신한다.

## 카드

이동·확대가 목표값에 도달하면 RectTransform에 같은 값을 계속 쓰지 않는다.
호버·드래그·우클릭 취소 동작은 유지한다.

## 검증

기존 `MapPresentationValidation.Run`에 지도 오브젝트 재사용과 HUD 지연 갱신 검증을 연결했다.
워밍업 후 같은 상태의 지도 Refresh를 200번 호출해 관리 메모리 할당량을 측정한다.
이는 해당 코드 경로의 할당 검증이며, 게임 전체의 FPS 개선이나 총 메모리 절감률을 뜻하지 않는다.
전체 경로는 기존 카드·맵·전투·강화·보상 검증을 함께 실행한다.
