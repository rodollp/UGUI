# 카드 상점

맵에서 가게 아이콘이 붙은 상점 칸을 선택하면 바로 상점이 열린다.
기본 맵에는 회차마다 4층부터의 일반 층 중 한 곳에 상점 칸이 생성된다.
상점에 도달하려면 첫 전투 칸에서 최소 세 번 이동해야 한다.

## 판매

- DefaultShop의 CardPool에서 서로 다른 카드 5종을 무작위로 선택한다.
- 타격·방어(수비)와 해당 강화 카드는 ExcludedCards로 제외한다. 보유 중인 다른 카드의 중복 구매는 가능하다.
- 현재 상품 풀은 강타·위협·철벽·유탄·회전베기 데이터 5종이다. 풀을 늘리면 진열 조합도 달라진다.
- 가격은 등급 구분 없이 50골드이며, 무작위 한 자리는 50% 할인된 25골드다.
- 가격은 Assets/Datas/Adventure/DefaultShop.asset의 CardPrice에서 변경한다. 정수 할인 가격은 절반을 내림한다.
- 상품과 할인 자리는 입장 시 한 번 정한다. 미리보기·덱 확인·일시정지로 재추첨하지 않는다.
- 카드 클릭으로 확대 확인 후 '구매 확정'을 누르면 골드를 차감하고 새 카드 인스턴스를 덱에 추가한다.
- 구매한 상품은 품절이며 한 자리에서 여러 번 구매할 수 없다. 골드가 부족하면 구매할 수 없다.
- 강화 체크란은 미리보기다. 구매로 강화가 적용되지는 않는다.

## 제거

- 제거 비용은 회차 시작 시 50골드이며, 성공할 때마다 50골드씩 오른다: 50 → 100 → 150 → ….
- 같은 회차의 다른 상점에서도 비용이 이어진다. 초기 보유 골드는 기존처럼 0이다.
- 상점당 횟수 제한은 없으며, 현재 비용을 지불할 수 있으면 다시 이용할 수 있다.
- 전체 보유 덱을 스크롤 목록으로 표시한다. 기본·강화 카드 모두 제거 가능하다.
- 카드를 클릭해 확대 확인하고 '제거 확정'을 눌렀을 때 선택한 인스턴스 한 장만 제거한다.
- 목록 복귀·취소·잔액 부족·유효하지 않은 카드 선택은 골드나 다음 제거 비용을 바꾸지 않는다.

## 이동과 검증

ESC는 확대 화면 → 제거 목록 → 상점 순서로 돌아간다. 상점에서 ESC 또는 '상점 나가기'는 노드를 완료하고 맵으로 돌아간다.
나간 상점은 다시 방문할 수 없다. 체력·골드·변경된 덱과 제거 비용은 회차에 유지된다.

맵의 Shop 필드에서 상점 데이터를 지정한다. Tools → Shop → Configure Card Shop으로 기본 맵의 상점 연결을 복구할 수 있다. 기존 상점 가격과 상품 풀은 보존한다.
모델 검증: Tools → Shop → Validate Shop Models. 씬을 변경하거나 저장하지 않는다.

이번 변경은 런타임·에디터 컴파일과 엔진 대역을 사용하는 222개 로직 검사로 검증했다.
Unity 실제 화면·레이아웃·클릭·스크롤 검증은 별도로 필요하다.
