# 보유 덱과 보상 건너뛰기

맵·전투·사건·결과 화면 오른쪽 위의 **보유 덱**을 누르면 이번 회차의 전체 덱을 연다.
전투의 뽑기/손패/버림 더미 구분 없이 MasterDeck의 각 카드를 표시하며, 중복 카드는 각각 표시한다.
강화 상태와 전체 장수를 확인할 수 있고 휠 또는 드래그로 세로 스크롤한다.
덱 창에서는 전투와 타이머를 멈추며, 닫기 또는 ESC로 원래 화면에 복귀한다.
열람으로 카드나 회차 상태를 바꾸지 않는다.

보유 덱의 카드를 좌클릭하면 카드를 1.8배로 확대하여 표시한다.
카드 아래 **강화 적용시** 체크란을 켜면 이름·비용·효과가 강화 후 데이터로 바뀌고,
체크를 해제하면 현재 카드로 돌아간다. 미리보기는 별도 인스턴스를 사용하여 실제 강화나 비용 지불을 하지 않는다.
이미 강화된 카드는 체크된 상태로, 강화 데이터가 없는 카드는 체크 해제 상태로 체크란을 비활성화한다.
확대 화면에서 ESC·배경·덱으로를 누르면 기존 덱 목록과 스크롤 위치로 돌아간다.
목록에서 ESC를 한 번 더 누르면 덱 창을 닫고 게임을 재개한다.

전투 승리 후 카드 3장 중앙 아래의 **다음으로**를 누르면 카드를 받지 않고 진행한다.
카드를 먼저 선택한 경우에는 선택한 카드를 유지하고 진행한다.
골드는 승리 시 지급된 그대로 유지하며, 선택과 건너뛰기는 한 번만 처리한다.
맵 모드에서는 맵으로 복귀하고, 순차 전투 모드에서는 다음 전투를 시작한다.

CardGame 씬에 연결되어 있다. 씬 연결을 다시 구성할 때는
`Tools → Cards → Configure Deck Viewer and Reward Skip`을 사용한다.
자동 구성과 모델 검증 진입점은 `DeckRewardSetup.ConfigureAndValidate`이다.
