# 분기 맵과 사건

## 실행 흐름

CardGame 씬에서 START를 누르면 전투 대신 맵을 연다.
맨 아래에서 시작하며 밝은 노드 중 하나를 클릭한다.
선택한 노드가 전투이면 해당 적 조합을 생성한다.
승리 후 골드와 카드 보상을 처리하고 '맵으로'를 누르면 같은 맵으로 돌아온다.
다음 전투는 자동으로 시작되지 않는다.
완료한 노드에 연결된 바로 다음 층의 노드만 선택할 수 있다.
완료한 노드를 반복해서 이용하거나 다른 경로로 순간 이동할 수 없다.
마지막 보스의 보상을 처리하면 맵에서 탐험 완료를 표시한다.

## 노드 종류

| 종류 | 내용 |
| --- | --- |
| 전투 | 기존 고블린/수호병 조합 중 하나와 전투 |
| 정예 | 정예 수호병과 전투, 골드 25~35 및 카드 보상 |
| 보스 | 마지막 층의 우두머리, 골드 35~50 및 카드 보상 |
| 사건 | 제단·상인·가방 중 하나의 선택형 사건 |
| 휴식 | 최대 체력의 30% 회복, 카드 한 장 강화 또는 지나가기 |
| 보물 | 골드 25 획득 또는 지나가기 |

골드와 체력 수치 등은 샘플 값이며 에셋에서 바꿀 수 있다.
상인은 현재 카드 한 장을 골드와 교환하는 사건이다. 별도의 다중 상품 상점 UI는 없다.

## 맵 설정

RunManager의 Map Data에 Assets/Datas/Adventure/DefaultMap.asset이 연결되어 있다.
모든 경로는 보스를 포함해 6개 노드로 고정한다. 보스 전까지 3개 열의 노드, 마지막 층에 보스 1개다.
방문 순서는 1번째 전투 → 2번째 사건/전투/정예 → 3번째 보물 → 4번째 전투/사건/정예 → 5번째 휴식 → 6번째 보스다.
3번째 층의 모든 노드를 보물로 고정하며 다른 층에는 보물을 생성하지 않는다.
따라서 갈림길에서 어떤 경로를 선택해도 세 번째 방문에 보물을 한 번 만난다.
모든 노드는 시작점에서 도달 가능하고 보스로 이어지는 길을 가진다.
회차마다 연결과 적/사건 배치가 생성되고 회차 안에서는 유지된다.

- Rows: 읽기 전용 6층. 기존 에셋의 Rows 값과 관계없이 동일하게 적용한다.
- Battles / Elites / Bosses: 각 전투 종류의 EncounterData 후보.
- Events: 사건 후보. 노드 생성 시 한 번 선택한다.
- Rest / Treasure: 휴식과 보물의 사건 데이터.
- Use Fixed Seed / Seed: 테스트용 맵 재현. 전투 보상 난수는 별도다.

Map Data를 지정하지 않은 경우 기존 StageData 순차 진행을 호환 모드로 유지한다.
실제 CardGame 씬은 맵 모드를 사용하며 기존 전투 자동 검증만 호환 모드로 실행한다.
새 회차를 시작하면 맵·체력·덱·골드를 초기화한다. 앱 종료 후의 진행 저장은 아직 없다.

## 사건 추가

Create → Map → Event로 MapEventData를 만든 뒤 Events 후보에 추가한다.
Title, Description과 최대 3개의 Choices를 설정한다.

각 선택지에서 다음을 조합할 수 있다.

- Gold Cost / Health Cost: 비용.
- Gold Gain: 골드 획득.
- Heal Amount / Heal Percent: 고정 회복과 최대 체력 비율 회복.
- Card: 지정 카드 1장을 회차 덱에 추가.
- Upgrade Card: 보유 카드 한 장을 선택해 강화. 자세한 설정은 CardUpgrades.md 참고.
- Result: 선택 후 표시할 결과 문구.

비용이 부족한 선택지는 비활성화한다. 체력 비용으로 사망하는 선택은 허용하지 않는다.
최소 하나는 무료 선택지를 넣어야 한다. '지나간다'도 가능하다.
한 노드의 효과는 한 번만 처리하고 결과 확인 후 맵으로 돌아온다.

## 구성과 검증

Tools → Map → Configure Adventure로 샘플 데이터와 씬 연결을 구성한다.
기존 사건·맵·정예 데이터의 편집 값과 RunManager에 연결한 Map Data는 보존한다.
이 메뉴는 맵/사건 UI 배치와 START 버튼의 연결을 다시 설정한다.
전투의 적 행동을 바꾸려면 기존처럼 각 EncounterData가 가리키는 EnemyData를 편집한다.

배치 검증:

```text
Unity.exe -batchmode -projectPath "<GameUIUXLab 경로>" -executeMethod MapSetup.ConfigureAndRun -logFile "<로그 경로>"
```

16개 시드의 모든 가능한 경로가 보스 포함 6개 노드인지, 보물이 3번째에만 한 번 나오는지,
연결성, 층 건너뛰기/재방문 차단, 실제 START/노드/보상 클릭,
맵·전투·사건의 자원 유지, 비용 차감, 회복, 사건 중복 방지, 보스 완료,
패배 후 진행 차단과 새 회차 시작을 확인한다.
이후 기존 전투·디버프·보상 회귀 검증도 실행한다.
그래픽 모드에서는 map-preview.png와 event-preview.png를 프로젝트의 두 단계 위에 저장한다.
