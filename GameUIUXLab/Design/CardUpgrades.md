# 카드 강화

휴식에서 회복 대신 카드 강화를 선택하거나, 사건에서 길가의 대장장이를 만나 카드를 강화한다.
보유 덱 보기와 같은 스크롤 목록에 강화 가능한 카드를 전부 표시한다. 중복 카드도 각각 한 장씩 표시한다.
목록에는 현재 카드 모습을 표시하고, 좌클릭하면 1.8배 확대된 강화 후 미리보기를 연다.
카드 아래 '강화 적용시' 체크를 해제하면 현재 모습으로, 다시 체크하면 강화 후 모습으로 바뀐다.
미리보기는 별도 인스턴스를 사용하며 원본 카드와 회차 덱을 변경하지 않는다.
'강화 확정'을 누르면 선택한 한 장만 강화한다. 체크 상태와 무관하게 확정은 강화를 적용한다.
'목록으로'·배경 클릭·ESC는 확대 창을 닫고 기존 목록과 스크롤 위치로 돌아간다.
목록의 돌아가기 또는 ESC는 비용 없이 원래 사건 선택지로 돌아간다.
강화 확정 시에만 비용과 사건 완료를 처리한다. 목록은 휠과 카드 위 드래그로 스크롤할 수 있다.
휴식에서 강화하면 체력 회복은 받지 않는다.

| 카드 | 기존 | 강화 |
| --- | --- | --- |
| 타격 | 피해 6 | 피해 9 |
| 방어 | 방어도 5 | 방어도 8 |
| 강타 | 피해 8, 취약 2턴 | 피해 12, 취약 3턴 |
| 위협 | 약화 2턴 | 약화 3턴 |
| 철벽 | 방어도 8 | 방어도 11 |

카드 한 종류를 하나의 CardData 에셋에서 편집한다. Inspector의 기본·강화 영역에서 이름, 비용, 대상, 일러스트와 효과 순서를 설정한다. 새 카드는 Create → Scriptable Objects → CardData로 만들고, 강화판을 쓰는 카드에는 '강화 가능'을 켠다. '효과 추가'로 추가한 효과는 같은 카드 파일에 저장한다.
CardInstance는 원본 CardData를 참조하며, '강화 확정' 후 선택한 한 장의 강화 여부로 사용할 버전을 결정한다.
강화는 해당 회차 덱과 다음 전투에 유지된다. 새 회차에서는 초기화된다. 앱 종료 후 저장은 제공하지 않는다.

MapEventChoice의 Upgrade Card를 켜면 다른 사건에도 강화 선택지를 넣을 수 있다.
기존 Gold Cost/Health Cost도 함께 설정할 수 있으며 확정 시 결제한다.
강화할 카드가 없으면 강화 선택지는 비활성화한다. 사건에는 강화와 무관하게 무료로 나갈 선택지가 필요하다.

Tools → Cards → Configure Upgrades로 샘플과 씬 연결을 생성한다.
기존 Upgraded Card 연결과 이미 추가된 강화 선택지는 보존한다.
전체 검증: `-executeMethod UpgradeSetup.ConfigureAndRun`.
