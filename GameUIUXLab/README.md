# GameUIUXLab | 덱빌딩 로그라이트

**Unity와 생성형 AI를 활용한 턴제 덱빌딩 로그라이트 포트폴리오 프로젝트**

시작 덱으로 탐험을 시작해 지도에서 경로를 고르고, 턴제 전투와 이벤트를 거치며 덱을 바꾸는 게임 프로토타입입니다. 전투에서 남은 에너지를 어디에 쓸지, 지도에서 어느 경로를 택할지, 보상과 상점에서 어떤 카드를 덱에 남길지가 다음 전투에 영향을 줍니다.

## 플레이 흐름

1. **경로 선택** — 지도에서 다음 노드를 선택합니다. 일반 전투, 정예 전투, 상점, 휴식과 이벤트를 거쳐 보스에 도전합니다.
2. **턴제 전투** — 손패에서 카드를 드래그해 사용합니다. 적의 다음 행동 표시와 남은 에너지를 보고 공격과 방어를 결정합니다. 턴을 마치면 남은 손패를 버리고, 드로우 더미가 비면 버림 더미로 다시 구성합니다.
3. **덱 구성** — 전투 보상과 상점에서 카드를 획득하고, 상점에서 카드를 제거하거나 이벤트에서 강화해 다음 전투를 준비합니다.

## 주요 구현

| 영역 | 구현 내용 |
| --- | --- |
| 런과 전투 상태 | `RunManager`가 지도 진행, 골드, 런 덱을 관리합니다. `MasterDeck`과 `BattleDeck`을 분리해 카드 획득·제거·강화와 전투 중 드로우·버리기를 각각 처리합니다. |
| 카드 데이터와 효과 | 카드 데이터와 효과를 분리하고 피해, 방어, 드로우, 에너지, 상태이상 등을 카드별로 구성했습니다. `CardTargetResolver`가 카드 유형에 맞는 대상을 처리합니다. |
| 지도와 보상 | `RunMapGenerator`가 시드 기반으로 지도를 생성합니다. `AdventureController`가 노드 선택, 이벤트, 상점과 카드 강화를 연결합니다. |
| 전투 UI | UGUI로 손패 자동 배치, 마우스 오버 강조, 드래그 타기팅, 적 행동 표시, HP·방어도·에너지 HUD를 구현했습니다. 카드 UI와 토스트 메시지에는 오브젝트 풀링을 적용했습니다. |

## AI 활용

- **UI 이미지 제작** — GPT로 전투 HUD에 적용한 체력바 이미지를 제작했습니다. [체력바 UI 작업 기록](https://github.com/rodollp/UGUI/commit/3420ffadad58c6290728d6b8c48894d10079fa2c)
- **개발 협업** — Codex를 개발 보조 도구로 활용했습니다. GitHub에서 개발용과 제출용 버전을 분리하고, 저장소의 코드와 변경 이력을 바탕으로 포트폴리오 문서를 정리했습니다.

## Unity에서 실행

- **환경** — Unity `6000.6.9f1`, C#, UGUI, Unity Input System
- Unity Hub에서 이 브랜치의 `GameUIUXLab` 폴더를 엽니다.
- Unity 에디터의 Project 창에서 `Assets/Scenes/CardGame.unity`를 열고 **Play**를 누릅니다.
